# Решающие деревья и бэггинг

Реализация решающего дерева с нуля и исследование влияния бэггинга на качество модели.

## Что реализовано

**Решающее дерево:**
- Поиск оптимального порога через критерий Джини
- Поддержка вещественных и категориальных признаков
- Ограничения: max_depth, min_samples_split, min_samples_leaf

**Эксперименты:**
- Визуализация разделяющих поверхностей на 2D-датасетах
- Сравнение своей реализации со sklearn
- Анализ смещения и разброса при бэггинге

## Стек

Python, numpy, scikit-learn, matplotlib, seaborn
